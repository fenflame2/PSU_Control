# E3640A bench panel · 0.3.0

Linux X11 front panel and serial CLI for a single HP, Agilent or Keysight E3640A. Both run from the same Python source. Requires Python 3.6 or newer. The GUI uses Tk. The CLI and serial transport use only the standard library.

## Ubuntu 22.04 VM

    sudo apt install python3 python3-tk
    python3 e3640a.py --demo

## Red Hat Enterprise Linux 8

    sudo dnf install python3 python3-tkinter
    python3 e3640a.py --demo

Use the distribution Python matching the installed Tk package. Launch from an X session or an SSH session with X11 forwarding. No compilation or pip install is required. The distribution package repositories must be available for installation. For an offline machine with Python and Tk already installed, copy and extract this ZIP.

## Try it offline

Demo starts at 5 V, 1 A limit, 10 Ω load, output disabled. Click **Output OFF** to enable it. In METER view expect 5.000 V, 0.500 A and CV. Change **Demo load** to 2 Ω. Expect 2.000 V, 1.000 A and CC. Press **Display Limit** to see the 5 V and 1 A settings. This ideal resistive model simulates limiting and a latched OVP trip. It omits instrument settling times, measurement noise and external backfeed. Demo presets last for the session.

## Panel

- **Voltage / Current** selects the quantity adjusted by the knob. **Set value** accepts an absolute value. Changes take effect immediately, including with the output enabled.
- Turn the knob using the mouse wheel, drag vertically, or use the keyboard Up/Down keys. The ◀/▶ buttons or Left/Right keys change the step size. The active step and units appear below the meter.
- **Display Limit** toggles setpoints and measured values. **Output** shows the enable state reported by the supply. A trip appears separately on the meter.
- **8 V / 3 A** and **20 V / 1.5 A** select the instrument range. The application limits new entries to nominal range ratings and displays the actual settings read back.
- **Over Voltage** opens the threshold, protection enable and trip-clear menu. Clearing a trip can restore power to the load.
- **Store / Recall** use the five instrument memories. Recall restores the saved output enable as well as the programmed limits.
- **CSV log** writes timestamped readbacks after each completed poll. Voltage and current are successive measurements. Stop with **Stop CSV log**. Separate demo and bench logs by filename.
- **View / Local** returns live control to the physical front panel and closes the app. In demo it returns to the meter. Closing a healthy live session also requests local control. Neither exit path sends an output enable/disable command.

## Connect the instrument

1. On the supply select RS-232, 9600 baud, parity NONE (8 data bits). Two stop bits are fixed.
2. Use a true RS-232 PC port or USB–RS-232 adapter with working modem lines and a DTE-to-DTE null-modem cable carrying DTR/DSR. Refer to Keysight Figure 2-3 for wiring. Keep the optional relay-output jumpers removed for serial use.
3. Pass the USB adapter through to the Ubuntu VM. Inspect the device with `ls -l /dev/serial/by-id/` or `ls -l /dev/ttyUSB*`. Your account needs read/write access. On Ubuntu, membership in dialout is commonly needed. Log in again after a group change.
4. Start with a status query, substituting your actual device name.

       python3 e3640a.py --port /dev/ttyUSB0 --status
       python3 e3640a.py --port /dev/ttyUSB0

The app checks the model with *IDN?, enters remote mode and reads the existing settings. Startup sends no reset, recall, setpoint or output command. The serial link runs exclusively and the program checks DSR before sending and asserts DTR to accept replies. A timeout disables the controls. After a cable failure, use the physical panel to verify output state and relaunch to reconnect. The application never substitutes simulated readings for lost hardware.

## CLI

    python3 e3640a.py --demo --status
    python3 e3640a.py --port /dev/ttyUSB0 --set current 0.25
    python3 e3640a.py --port /dev/ttyUSB0 --set voltage 3.3
    python3 e3640a.py --port /dev/ttyUSB0 --set output on
    python3 e3640a.py --port /dev/ttyUSB0 --set output off

Each invocation opens its own session, prints a JSON snapshot and exits. Close the GUI before using the CLI on the same port. Other controls are `--set range P8V`, `--set range P20V` and `--set ovp 6.0`. Every CLI demo invocation starts a fresh simulation.

## Verification and scope

    python3 -m unittest -v

Tests exercise the demo load, limiting, OVP and presets, plus a pseudo-terminal transaction from identification through readback, output control and return to local. The pseudo-terminal test substitutes modem-line ioctls because PTYs lack physical modem pins. Verify the adapter, real supply and target operating systems on the bench. Release 0.3.0 covers manual panel operation, CSV capture and single CLI commands. Instrument calibration and triggered sequences are outside this release.
